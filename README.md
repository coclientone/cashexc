# Cashex Smart Transfer

Static landing page for Cashex Smart Transfer.

## Local preview

Open `index.html` directly in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Deployment

The `main` branch includes a GitHub Actions workflow that uploads the site as a GitHub Pages artifact. In the repository settings, enable **Pages → Build and deployment → GitHub Actions**. The project URL will be:

<https://coclientone.github.io/cashexc/>

The calculator uses demonstration exchange rates only. Connect live exchange-rate, payment, banking, compliance and notification providers before production use.
